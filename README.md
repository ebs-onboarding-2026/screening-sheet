# 선발평가지 자동 채점

참가신청서를 읽어 엑셀 선발평가지의 점수와 평가 메모를 채우는 실습입니다.
PDF · DOCX · HWPX로 제각각 들어온 신청서 7건을 훑어 동기 · 역량 · 직무연관성 세 항목을
매기고, 빈 양식에 그대로 써 넣습니다. 2026년 EBS 신규사원 연수과정 실습 결과물입니다.

## 구조

```
[샘플]참가신청서/                       신청서 원본 7건 (pdf · docx · hwpx 혼재)
퇴근후딴짓 바이브코딩 선발평가지.xlsx      빈 양식
퇴근후딴짓 바이브코딩 선발평가지_평가완료.xlsx  사람이 채운 기준 결과
tmp/evaluation/evaluate.mjs             평가지 작성 스크립트
tmp/evaluation/*.png                    작성 전 · 메모 · 결과 화면
outputs/01a09e9c/                       스크립트가 만든 재평가본
```

## 방식

`evaluate.mjs`는 빈 양식 시트를 열어 지원자별 점수를 채우고, 합계는 값이 아니라
`=SUM(C:E)` 수식으로 넣습니다. 증빙이 확인되지 않은 항목은 `재직 기재 / 증빙 미확인`처럼
판단 근거를 같이 남겨, 점수만 보고는 알 수 없는 유보 사항이 드러나게 했습니다.

## 고지

신청서와 지원자 이름은 모두 실습용으로 지어낸 **가상 데이터**입니다. 실제 인물이나
실제 지원 내역과 무관합니다.
